# Security

Please do not report security vulnerabilities, credentials, private server details, or exploitable proof-of-concept data in public issues.

Use GitHub's private vulnerability-reporting channel for this repository when it is available. If private reporting is unavailable, contact the Vonix.Network maintainers through a private authenticated channel and include only the minimum information needed to reproduce the issue.

For ordinary bugs, compatibility reports, and reproducible performance results, open a GitHub issue with Minecraft version, Forge version, Java version, mod list, configuration scope, and sanitized logs. Never attach secrets or signed/private URLs.

Threaded Horizons is experimental software. Back up worlds before testing and do not assume that a successful startup proves data safety or production readiness.
